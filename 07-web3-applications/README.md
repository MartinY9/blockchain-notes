# 第七篇 Web3 核心应用

> NFT / DeFi / DAO 是 Web3 的三大支柱。
> 理解每一个都从三个角度：**技术本质 + 真实价值 + 未来方向**。

---

## 7.1 NFT（非同质化代币）

### 技术本质

**NFT = 非同质化 Token（Non-Fungible Token）**：每一个都独一无二、不可互换（而 ETH/USDT 是同质化的，1 个和另 1 个等价）。

本质是**链上的所有权凭证 / 唯一标识**，不是图片本身。

### 标准（以太坊）

- **ERC-721**：每个 token 有唯一 ID，一个合约管理一系列独一无二的资产（数字艺术、域名）。
- **ERC-1155**：**多 Token 标准**，一个合约同时管理同质化 + 非同质化资产，支持批量转移，Gas 更省。适合游戏（一把「传奇剑」是 NFT，一堆「金币」是 FT）。

> 常见误区：NFT 链上通常只存**元数据 URI（指向图片的链接）**，图片本身常存 IPFS / 中心化服务器。所以「NFT 图片能不能被篡改/丢失」取决于存储方案——这是理解 NFT 时容易忽略的点。

### 应用与未来方向

- 当前：数字艺术、PFP 头像、游戏资产、IP 授权、域名（ENS）。
- **未来方向：从「图片收藏」→「资产凭证 / 权益载体」。** NFT 作为**唯一凭证**的能力，可承载房产证、门票、会员权益、身份、RWA 确权凭证（见第八篇）。收藏属性是起点，**凭证化**才是长期价值。

---

## 7.2 DeFi（去中心化金融）

**核心：无需银行 / 中介的金融系统。** 用智能合约替代传统金融中介，代码即规则、资产自托管、全球可组合（「货币乐高」）。

三大基础组件：

- **DEX（去中心化交易所）**：
  - **AMM（自动做市商）**：如 Uniswap，用 `x * y = k` 恒定乘积公式定价，流动性提供者（LP）注入资金池赚手续费，取代了传统订单簿撮合。
  - 关键概念：**滑点、无常损失（Impermanent Loss）、流动性池**。
- **Lending（借贷）**：如 Aave、Compound。**超额抵押**借贷（抵押 150% 借 100%），利率由供需算法决定，**清算机制**保证坏账可控。
- **Stablecoin（稳定币）**：锚定法币（通常 1 美元）。
  - **法币抵押型**：USDT、USDC（中心化机构持有储备）。
  - **加密资产抵押型**：DAI（超额抵押 ETH 等生成）。
  - **算法型**：如已崩盘的 UST（Terra）——算法稳定币的**死亡螺旋**风险的典型教训。

关键风险：**预言机操纵、闪电贷攻击、重入、清算连锁、可组合性带来的系统性风险**（见第十二篇）。

---

## 7.3 DAO（去中心化自治组织）

**去中心化组织**：用智能合约 + 代币治理来协调一群人，无传统公司层级。

- **治理代币**：持币即投票权，对提案（资金使用、参数调整、协议升级）投票。
- **链上金库（Treasury）**：由多签 / 合约管理，按投票结果执行。
- 典型：MakerDAO、Uniswap DAO、投资 DAO、社区 DAO。
- 挑战：投票率低、巨鲸垄断（富者话语权大）、链上治理与链下法律实体的衔接、治理攻击（借票操纵投票）。

---

## 本篇小结

- NFT 的本质是链上唯一所有权凭证（不是图片本身，图片常在 IPFS）；ERC-721 单一资产、ERC-1155 批量+混合。价值方向是从收藏走向凭证化。
- DeFi 用合约替代中介，三大件是 DEX（AMM 定价）、借贷（超额抵押+清算）、稳定币（三类，算法型有死亡螺旋风险）。
- DAO 用代币治理协调组织，核心挑战是投票率、巨鲸垄断与链下法律衔接。
