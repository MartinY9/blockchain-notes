# 第五篇 区块链扩展技术

> 区块链最大的工程难题是**扩容（Scalability）**。
> 核心矛盾：L1 要保证去中心化和安全，就无法无限提升 TPS。解法分两条路线：**做大 L1** 或 **把计算搬到 L2**。

---

## 5.1 Layer1 扩容（把 L1 本身做大做快）

三个方向：

1. **共识优化**：更快的最终性、更高效的通信（如 HotStuff、Narwhal，见第三篇）。
2. **并行执行**：让互不冲突的交易同时执行，而非串行。
   - Solana 的 **Sealevel**（基于交易预声明读写集调度）、Aptos 的 **Block-STM**（乐观并行 + 冲突检测重试）、Sui 的对象级并行。
3. **状态优化**：解决状态膨胀，让节点存得下、同步得快（状态过期、Verkle Tree、无状态客户端）。

代表：**Solana**（单体高性能链，靠硬件 + PoH + 并行执行冲 TPS）。

> 权衡：L1 扩容往往以**提高节点硬件门槛**为代价，牺牲部分去中心化。Solana 就是典型——高性能但节点少、门槛高。

---

## 5.2 Layer2（把执行搬到链下，安全性锚定 L1）

核心思想：**在 L1 之外执行大量交易，只把「结果 + 证明/数据」提交回 L1**，从而复用 L1 的安全性，同时突破 L1 的性能上限。主流是 **Rollup**。

### Rollup 总览

把大量交易在 L2 打包（roll up）执行，压缩后提交到 L1。分两大流派，区别在**「如何让 L1 相信 L2 的结果是对的」**：

### Optimistic Rollup（乐观 Rollup）

代表：**Optimism、Arbitrum**。

- **假设诚实**：默认提交的结果是对的，先上链。
- **欺诈证明（Fraud Proof）+ 挑战期**：设一个挑战窗口（通常 7 天），任何人发现结果错误可提交欺诈证明，验证后惩罚作恶者、回滚错误。
- **优点**：兼容 EVM（EVM-equivalent）、开发迁移成本低。
- **缺点**：**提现慢**（要等 7 天挑战期）、安全依赖「至少有一个诚实验证者会挑战」。

### ZK Rollup（零知识 Rollup）

代表：**zkSync、StarkNet、Polygon zkEVM、Scroll、Linea**。

- **有效性证明（Validity Proof）**：每批交易生成一个**零知识证明（ZK-SNARK/STARK）**，L1 上的验证合约**数学上验证**「这批交易执行正确」。
- **优点**：**无需挑战期**（提交即最终），提现快、安全性更强（不依赖诚实假设，靠密码学）。
- **缺点**：生成证明计算量大（proving 成本）、实现 zkEVM 技术难度高、早期兼容性较弱（正快速改善）。

### Optimistic vs ZK 对比

| 维度 | Optimistic Rollup | ZK Rollup |
|------|-------------------|-----------|
| 正确性保证 | 经济博弈（欺诈证明） | 密码学（有效性证明） |
| 最终性/提现 | 慢（挑战期 ~7 天） | 快（证明验证即最终） |
| EVM 兼容 | 高（成熟） | 逐步提升（zkEVM 难点） |
| 计算成本 | 低（只在争议时算） | 高（每批都要生成证明） |
| 信任假设 | 至少一个诚实挑战者 | 无需信任，靠数学 |

> 趋势理解：长期看 **ZK Rollup 更接近终局**（密码学保证 + 快最终性），但短期 Optimistic 因兼容性和成本领先。二者正在收敛——ZK 在补兼容性，Optimistic 在探索 ZK 化。

### 其他 L2 / 相关

- **State Channel（状态通道）/ Lightning Network（闪电网络）**：链下多次交互，只把开/关通道上链。适合高频小额（如比特币闪电网络）。
- **Plasma**：早期方案，已基本被 Rollup 取代（数据可用性问题）。
- **Validium**：类 ZK Rollup 但数据放链下（更便宜但引入 DA 信任）。

---

## 5.3 数据可用性 DA（Data Availability）

代表：**Celestia、EigenDA、以太坊 Danksharding（EIP-4844 blob）**。

### 问题：区块的数据到底存在哪里、大家能不能拿到？

Rollup 要能被验证、能重建状态，就必须保证**「打包的交易数据是公开可得的」**。如果数据被藏起来（DA 失效），即使有欺诈证明也没法构造挑战、用户也无法退出——这是 Rollup 安全的隐藏命门。

- **为什么 DA 是瓶颈**：把所有 L2 数据都发到 L1（calldata）非常贵。DA 层专门优化「便宜且可验证地保证数据可得」。
- **数据可用性采样（DAS）**：轻节点随机抽样下载区块的一小部分数据；只要大量节点采样都成功，就能以极高概率确信「全部数据可得」，无需任何单节点下载全部数据。这是 **Celestia** 和以太坊 **Danksharding** 的核心技术。
- **EIP-4844（Proto-Danksharding，blob 交易）**：给以太坊引入临时存储的 **blob** 空间，专供 Rollup 存数据，大幅降低 L2 成本——2024 年上线后 L2 手续费显著下降。

> **模块化区块链**（见第一篇）本质就是把 DA 单独拆成一层，是「执行 / 结算 / 共识 / 数据可用性」四层分离思想的落地。

---

## 本篇小结

- 扩容两条路：做大 L1（并行执行、共识优化、状态优化，代价是去中心化）或搬到 L2（Rollup）。
- Rollup 的核心分歧是「怎样让 L1 相信 L2 结果」：Optimistic 用欺诈证明+挑战期（慢但兼容好），ZK 用有效性证明（快且更安全但成本高）。
- 数据可用性（DA）是 Rollup 的隐藏命门；DAS 让轻节点不下载全部数据也能确信数据可得。
- EIP-4844 的 blob 大幅降低了 L2 成本，是模块化路线的关键一步。
