# 区块链核心知识笔记

> 整理的一套区块链技术学习笔记，覆盖从基础原理到前沿趋势。
> 目标不是记住名词，而是理解一条主线：**每一代技术在解决上一代的什么瓶颈，代价又是什么。**

阅读时始终带着三个问题去理解每个技术点：

1. **它从哪来** —— 解决了上一代的什么问题？
2. **它的代价是什么** —— 在「去中心化 / 安全 / 性能」这个不可能三角上，牺牲了什么、换来了什么？
3. **它往哪去** —— 在产业趋势（RWA、跨链、Web3、AI + Crypto）里处于什么位置？

## 贯穿全书的一条主线

> 区块链的历史，就是在 **去中心化程度 / 安全性 / 性能（可扩展性）** 这个「不可能三角」上不断做取舍、并用工程手段把三角撑大的历史。
>
> 遇到任何新技术，先问自己：**它在这个三角上牺牲了什么、换来了什么？**
>
> 区块链的未来：
区块链会逐渐从“独立产品”变成一种可信协作基础设施。未来主要玩家不再只是纯区块链技术公司，而更多表现为数据基础设施公司、金融科技公司、资产数字化/RWA基础设施公司、可信计算公司和产业数字化平台。
>   1. 金融/RWA/跨境资产数字化。资产 → 数字化 → 可编程 → 可交易 → 自动清结算。结合支付基础：区块链 + 支付 + 跨境金融 + RWA + 稳定币/Tokenized Deposit + 合规基础设施；（蚂蚁、银行、持牌金融机构）
>   2. 数据要素/可信数据空间。隐私数据（医疗等）授权 → 隐私计算 → 使用 → 链上审计 → 收益结算；（趣链、长安链）
>   3. 供应链金融。核心企业信用 → 应收账款数字化 → 一级供应商 → 二级供应商 → 银行融资；（银行、供应链平台）
>   4. 数字身份/可验证凭证/可信身份基础设施。个人/企业身份 → DID → 可验证凭证 → 跨机构认证 → 数据授权 → 业务办理；
>   5. AI × 区块链 × 可信数据。数据提供者 → 可信数据空间 → AI Agent/模型调用 → 调用授权 → 结果验证 → 使用计量 → 自动结算；（AI支付，x402）
