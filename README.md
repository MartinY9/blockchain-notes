# 区块链核心知识笔记

> 我自己整理的一套区块链技术学习笔记，覆盖从基础原理到前沿趋势。
> 目标不是记住名词，而是理解一条主线：**每一代技术在解决上一代的什么瓶颈，代价又是什么。**

阅读时始终带着三个问题去理解每个技术点：

1. **它从哪来** —— 解决了上一代的什么问题？
2. **它的代价是什么** —— 在「去中心化 / 安全 / 性能」这个不可能三角上，牺牲了什么、换来了什么？
3. **它往哪去** —— 在产业趋势（RWA、跨链、Web3、AI + Crypto）里处于什么位置？

## 建议阅读顺序

```
区块链历史 → 架构 → 共识 → 跨链 → RWA/Web3 → 分布式系统 → 系统设计
```

按这个顺序，先建立整体框架，再逐层深入，最后能把知识点串成一条完整的演进脉络。

---

## 贯穿全书的一条主线

> 区块链的历史，就是在 **去中心化程度 / 安全性 / 性能（可扩展性）** 这个「不可能三角」上不断做取舍、并用工程手段把三角撑大的历史。
>
> 遇到任何新技术，先问自己：**它在这个三角上牺牲了什么、换来了什么？**
