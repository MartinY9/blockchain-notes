# 第十二篇 区块链安全

> 安全知识分三层：**智能合约漏洞 → 共识/网络攻击 → 桥/跨链攻击**。
> 每种漏洞都从「原理 + 例子 + 防御」三点去理解。

---

## 12.1 智能合约漏洞

### 重入攻击（Reentrancy）

- **原理**：合约在**更新自身状态之前**就向外部地址转账/调用，外部合约在回调（fallback）里**再次调用**原函数，反复提款。经典案例：**The DAO 事件（2016，导致以太坊硬分叉）**。
- **防御**：
  - **Checks-Effects-Interactions 模式**：先检查、再改状态、最后才做外部调用。
  - **重入锁（ReentrancyGuard / mutex）**。
  - 优先用 pull-payment 模式或限制转账 gas。

### 整数溢出 / 下溢（Integer Overflow / Underflow）

- **原理**：`uint256` 超过最大值回绕到 0（或反之），导致余额被刷爆等。
- **防御**：Solidity 0.8+ **默认检查溢出**（自动 revert）；早期用 `SafeMath` 库。

### 访问控制缺陷（Access Control）

- **原理**：关键函数（提款、铸币、升级、`selfdestruct`）**缺少权限校验**或权限配置错误。经典：Parity 多签钱包因 `initWallet` 可被任意调用，被冻结约 5 亿美元。
- **防御**：`onlyOwner` / 基于角色的访问控制（RBAC，如 OpenZeppelin `AccessControl`）、多签管理、最小权限原则。

### 其他常见合约漏洞

- **预言机操纵 / 闪电贷攻击**：用闪电贷在一个区块内借入巨额资金，操纵 AMM 现货价格喂给依赖它的协议，套利后归还——DeFi 最常见的攻击。**防御**：用 TWAP（时间加权价格）、多预言机（Chainlink）、抗操纵喂价。
- **抢跑 / MEV（front-running）**：交易在 mempool 公开，攻击者插队获利（三明治攻击）。**防御**：commit-reveal、私有 mempool、滑点保护。
- **随机数可预测**：链上 `block.timestamp`/`blockhash` 做随机数可被操纵。**防御**：VRF（可验证随机函数）。
- **逻辑/升级漏洞**：代理合约存储冲突、未初始化实现合约（如 Nomad）。

## 12.2 共识 / 网络攻击

- **51% 攻击**：掌握全网多数算力（PoW）/ 质押（PoS），可重组链、双花。小市值 PoW 链常见受害。**防御**：提高攻击成本、更多确认数、检查点。
- **Sybil 攻击（女巫攻击）**：伪造大量虚假身份影响网络。**防御**：PoW/PoS 让「身份」需付出真实成本；联盟链靠准入/CA。
- **Eclipse 攻击（日蚀攻击）**：垄断某节点的所有对外连接，给它喂假的链视图，可配合双花/审查。**防御**：增加连接多样性、固定可信 peer、随机化 peer 选择。
- **长程攻击（Long-range，PoS 特有）**：用旧的验证者私钥重写历史。**防御**：弱主观性检查点（weak subjectivity）、Slashing。
- **DoS / 垃圾交易**：**防御**：Gas/手续费、mempool 限制、准入。

---

## 12.3 桥 / 跨链攻击（呼应第六篇）

**跨链桥是被盗金额最大的攻击面**——因为它把「一条链的安全」外包给了「一小群外部验证者或一段验证代码」。

- **私钥泄露 / 多签被攻破**：**Ronin（约 6.2 亿美元）** —— 5/9 多签私钥被社工获取。
- **验证机制漏洞**：**Wormhole（约 3.2 亿美元）** —— 签名验证 bug 伪造铸币；**Nomad（约 1.9 亿美元）** —— 错误初始化使任意消息被信任。
- **权限控制缺陷**：**Poly Network（约 6.1 亿美元）** —— 跨链管理合约权限校验漏洞。
- **Oracle 攻击**：桥/协议依赖的预言机被操纵。

**防御方向**：最小化信任（轻客户端 / ZK 桥）、去中心化验证者集、形式化验证关键代码、限额与熔断（rate limit / circuit breaker，被盗时限制单位时间提款）、实时监控异常大额提款、多重审计。

---

## 12.4 安全方法论

- **纵深防御**：代码审计 + 形式化验证 + 测试（含 fuzzing）+ 监控 + 漏洞赏金 + 限额熔断，多层叠加。
- **最小权限 + 时间锁**：管理权限用多签 + timelock，给社区反应时间。
- **可升级要谨慎**：升级权本身就是攻击面，需多签 + 延迟执行。
- **假设会被攻击**：设计熔断、暂停开关（circuit breaker / pausable）、灾难恢复预案。

---

## 本篇小结

- 合约层三大经典漏洞：重入（Checks-Effects-Interactions + 重入锁）、整数溢出（0.8+ / SafeMath）、访问控制（RBAC + 多签）；还有闪电贷+预言机操纵、MEV、随机数。
- 共识/网络层：51%、Sybil、Eclipse、长程攻击，防御核心是「让作恶有成本 + 增加连接多样性 + 检查点」。
- 桥是最大攻击面，根因是信任外包给少数验证者或有 bug 的验证代码；防御靠最小化信任 + 限额熔断 + 监控。
- 安全是纵深防御：审计 + 形式化验证 + 监控 + 时间锁 + 熔断，并始终假设会被攻击。
